Setting up the Assistant

The Assistant is the AI layer: live suggestion cards during the call and the report afterwards. It is off by default and Parrot works perfectly well as a recorder and transcriber without it. When you want it, flip it on in Settings → Assistant and pick who does the thinking.

Connect your accounts

Open Settings → Assistant → Set up the Assistant, or use the Assistant card on Home. Enable one or several connections for Claude / Claude Code, ChatGPT / Codex, Gemini, GitHub Copilot, a trusted custom CLI or Ollama.

For an account connection, follow Install and sign in and sign in through that CLI. Check verifies installation. Sign-in and plan limits are confirmed when a request runs. Parrot uses these signed-in CLIs for background assistance. Claude Desktop and other desktop MCP connectors separately let you ask those apps about saved meetings.

With Ollama, download and start a local model during setup or in Settings. The model shares your Mac with live transcription, so response time depends on the model and your Mac.

Automatic routing and model choices

Live assistance, reports and Ask share automatic routing. The Assistant uses an available enabled connection that supports the request and tries another eligible connection if it fails. Each integration has its own Auto setting and manual model choice in its connection settings. Auto keeps your manual choice saved.

Claude Code, Codex and GitHub Copilot support selected-window images. Gemini and custom CLI connections support text only. Images are sent only when screen context is allowed. Audio, transcription and transcript polish stay on this Mac.

Enabled account connections receive meeting text, matched document snippets and the context allowed by your privacy settings. With On-device only, account connections stay selected but are held, and Ollama can still run locally. See What leaves your Mac and The Assistant during a call.
